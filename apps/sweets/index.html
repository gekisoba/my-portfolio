ぽちっとスイーツ工場

スイッチをタップして材料を仕分け、機械で仕上げてトラックへ。ベルトコンベアの上でお菓子を作る、仕分けパズルです。

iPhone iPad STAGE 1〜5 は無料（製品版 ¥500・買い切り）
App Store で入手 ブラウザで体験版を遊ぶ

どんなゲームか

スイッチで仕分ける

材料はベルトに乗って次々に流れてきます。スイッチをタップして「通す」と「落とす」を切り替え、それぞれ行くべき場所へ送り分けます。

機械で仕上げる

オーブンで焼いて、クリームを塗って、いちごを載せる。機械は真下に来たものを何でも加工するので、送る順番をまちがえると「ぐちゃぐちゃ」になります。

17時までに出荷

できたお菓子をトラックに積んで、ノルマを目指します。不良品を積むと★が減り、不良品なしで満載にできれば★4つ。

全30面、29種類のお菓子

いちごクッキーから始まって、マカロン、パフェ、最後はウェディングケーキまで。作ったお菓子は「おかし図鑑」に載っていきます。

詰まったらヒント

どのスイッチで、どの材料をどう切り替えればいいかを、番号つきで教えてくれます。速さは ½ 倍から 3 倍まで変えられます。

工場長のひとこと

1日が終わると、工場長が結果にひとことくれます。うまくいった日も、ぐちゃぐちゃの日も。

画面

無料で遊べる範囲

STAGE 1〜5 は無料

最初の5面はそのまま遊べます。気に入ったら、製品版（¥500・買い切り）で STAGE 6〜30 の25面が遊べるようになります。

広告は見たいときだけ

広告は、自分で選んだときにだけ出ます。広告を見ると製品版の面を1回だけ試せるほか、時間切れのあとに30秒だけ残業できます（製品版なら残業は広告なし）。

ブラウザでも試せる

STAGE 1〜5 はブラウザの体験版でも遊べます。インストールする前に雰囲気を見たいときにどうぞ。

作りの話

ブラウザ版から1行ずつ移植

もとはブラウザで動く JavaScript のゲームです。ルールの部分を Swift に1行ずつ移し、ブラウザ版で記録した90回のプレイをアプリで再生して、結果がぴったり同じになることを確かめています。

お菓子の絵はコードで描いた

29種類のお菓子は、どれも Canvas の命令で描いたものです。アプリにはそれを書き出した画像を入れています。

音

BGM は画面ごとに5曲（Suno で作ったもの）。つなぎ目がわからない位置を探してループさせています。ボタンや出荷の効果音は、その場で波形から合成しています。

SwiftUI

画面も工場の描画も SwiftUI です。外部ライブラリは広告の SDK だけ。iPad では工場を大きく表示します。

サポート
