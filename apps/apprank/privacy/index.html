AppRank プライバシーポリシー

最終更新日: 2026年8月29日

「AppRank」（以下、本アプリ）は個人開発者が提供する macOS 向けアプリケーションです。本アプリにおけるデータの取り扱いについて、以下のとおり定めます。

1. 開発者が取得しない情報

本アプリの開発者は、利用者が登録したアプリ情報・キーワード・順位の記録を取得しません。開発者が運用するサーバーは存在せず、これらのデータを開発者が閲覧・収集する手段はありません。

2. 端末内に保存される情報

以下の情報は、お使いの Mac の中にのみ保存されます。

  • 登録したアプリの App ID
  • 追跡対象のキーワード
  • 取得した順位の履歴
  • 更新間隔などの各種設定

3. 外部サービスへの通信

順位情報の取得のため、Apple が一般に公開している以下の API に通信します。送信するのは検索キーワードと App ID のみで、利用者を識別する情報は含まれません。

接続先用途
iTunes Search APIキーワード検索結果および順位の取得
Apple Marketing Tools RSS フィードカテゴリ順位の取得
Apple 検索サジェストキーワード候補の取得

いずれも Apple が公開している API であり、App Store Connect のアカウント連携や認証キーの登録は必要ありません。

4. アカウントについて

本アプリはアカウント登録を必要としません。メールアドレスなどの個人情報を入力いただく場面はありません。

5. 広告・トラッキングについて

本アプリは広告を表示せず、利用状況の追跡（トラッキング）も行いません。解析ツールの類も組み込んでいません。

6. 購入について

本アプリの購入手続きは Apple の App Store を通じて行われます。クレジットカード番号などの決済情報は Apple が処理し、開発者がこれらの情報を受け取ることはありません。

7. お問い合わせ時の情報

お問い合わせフォーム（Google フォーム）をご利用いただく場合、利用者が任意で入力した内容が開発者に送信されます。これらの情報はお問い合わせへの対応および不具合の修正のみに使用し、他の目的には利用しません。

8. 第三者への提供

開発者は、利用者のデータを第三者に販売・提供することはありません。ただし、法令に基づく開示請求があった場合はこの限りではありません。

9. お問い合わせ

本ポリシーに関するご質問は、お問い合わせフォームまたは support@gekisoba.com よりご連絡ください。

10. 改定について

本ポリシーの内容は、必要に応じて変更されることがあります。重要な変更を行う場合は、本ページ上でお知らせします。
